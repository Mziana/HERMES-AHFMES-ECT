# AHFMES-ARE Interface

## Objective

Define a future controlled interface through which Hermes can observe and review AHFMES-ARE without becoming an ARE authority channel.

## Concept

```text
ARE state/artifact
      ↓
controlled export
      ↓
Hermes context
      ↓
external analysis
      ↓
structured review
      ↓
ARE evaluates independently
```

## Review artifact

The planned exchange should include:

- review identifier;
- target artifact/state;
- evidence references;
- observed facts;
- claims;
- contradictions;
- assumptions;
- unknowns;
- recommendations;
- severity;
- confidence.

The exact schema is intentionally deferred until the ARE-side interface is understood sufficiently.

## Prohibited shortcut

Do not inject free-form Hermes output directly into authoritative ARE state.
