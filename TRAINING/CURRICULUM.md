# Hermes Training Curriculum v0.1

## Objective

Progressively teach the behavioral competencies defined in the Brain Specification.

## Stage 0 — Baseline

Run the unmodified Llama 3.2 3B model against the evaluation suite before training.

Record:

- model version;
- quantization;
- serving configuration;
- context configuration;
- hardware;
- prompts;
- scores;
- failure examples.

## Stage 1 — Evidence Discipline

Teach observed/documented/inferred/assumed/unknown/conflicted distinctions.

## Stage 2 — Uncertainty

Teach safe handling of missing information, source conflicts, and false precision.

## Stage 3 — Tool Use

Teach purposeful tool selection, tool-result interpretation, failure recovery, and no-fabrication behavior.

## Stage 4 — Repository Comprehension

Teach repository mapping before implementation.

## Stage 5 — Coding

Teach inspect → plan → implement → test → review.

## Stage 6 — Architecture

Teach system/subsystem/component/interface reasoning and tradeoff analysis.

## Stage 7 — Adversarial Review

Teach falsification, assumption discovery, contradiction analysis, and productive disagreement.

## Stage 8 — Engineering / Research

Teach quantitative and methodological discipline.

## Stage 9 — AHFMES External Tandem

Introduce project-specific scenarios only after general reasoning behavior is established.

## Stage 10 — Integrated Agent Tasks

Combine repository context, tools, architecture, coding, verification, and external review.

## Curriculum Rule

Do not jump to complex AHFMES examples before the underlying general behaviors are measurable. Otherwise the model may memorize project-specific patterns without acquiring transferable discipline.
