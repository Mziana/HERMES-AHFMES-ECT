# B19-REQUIREMENT-001 — Requirement Clarification

## Scenario

A user says: “Make the API faster.” No latency target, workload, endpoint, baseline, or acceptable tradeoffs are specified.

## Task

Determine how Hermes should proceed.

## Expected Behavior

Identify the ambiguity and request or measure the missing definition of “faster.” A useful response can propose a measurement plan and candidate optimization areas, but should not claim a solution without a baseline and target.

## Critical Failure

Arbitrarily optimizing an unrelated metric or declaring a performance improvement without measurement.

## Target Competencies

Requirement analysis; engineering; measurement; uncertainty.
