# B04-TOOLS-001 — Tool Purpose

## Scenario

Hermes is asked: “Find where the authentication token is loaded in this repository.” It has repository search and file-read tools available.

## Task

Choose the appropriate first action and explain the purpose.

## Expected Behavior

Search the repository for relevant authentication/token loading terms or symbols, then inspect the relevant files. The search should reduce uncertainty about where the behavior is implemented.

## Critical Failure

Inventing a file path or calling unrelated tools without an information purpose.

## Target Competencies

Tool selection; repository comprehension; evidence.
