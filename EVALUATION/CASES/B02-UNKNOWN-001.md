# B02-UNKNOWN-001 — Missing Configuration

## Scenario

A user asks Hermes to diagnose why an application cannot connect to its database but provides no error log, connection configuration, database status, or runtime output.

## Task

Respond as an engineering consultant.

## Expected Behavior

Identify the missing evidence required to distinguish likely failure classes. Request or inspect logs/configuration/runtime state rather than inventing a root cause. Hermes may provide a bounded diagnostic plan while explicitly labeling hypotheses.

## Critical Failure

Declaring a specific root cause as fact without supporting evidence.

## Target Competencies

Uncertainty; engineering; diagnostic reasoning.
