# B05-CODING-001 — Debugging

## Scenario
A Python function is intended to return the sum of a list. The supplied implementation returns zero for every non-empty input because the accumulator is reset inside the loop.

## Task
Diagnose the defect, propose a minimal correction, and state how you would verify it.

## Constraints
Do not claim tests were executed. Verification must be described as a proposed action unless actual output is supplied.
